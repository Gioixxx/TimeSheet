# /sprint — Gestisce sprint corrente

## Input
`@.claude/memory/sprint.md` (crea se non esiste).

## Regole
- Non cancellare task completati — archivia
- Aggiorna data ultimo aggiornamento
- Operazioni: aggiungi task, completa, nuovo sprint

## Output
Stato sprint: task in corso, completati, progresso. Operazioni disponibili.
