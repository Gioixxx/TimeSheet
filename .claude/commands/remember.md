# /remember — Salva in memoria progetto

## Input
Informazione fornita dall'utente. Classifica: decisione, dominio, sprint, convenzione.

## Regole
- Scrivi in `decisions.md`, `domain.md`, `sprint.md` o `conventions.md`
- Non duplicare — aggiorna esistente se presente
- Crea file se non esiste
- Conferma cosa salvato e dove

## Output
Conferma scrittura, suggerimento `/remember` per nuove info
