# /onboard — Onboarding progetto

## Input
Tutti i file memoria: MEMORY.md, decisions.md, adr.md, domain.md, conventions.md, sprint.md, backlog.md, tech-debt.md. `git log -20`, `git branch -a`, file dipendenze.

## Regole
- Sintetizza — leggibile in 5-10 minuti
- Priorità a info che evitano errori
- Se memoria vuota, suggerisci `/remember`
- Solo lettura — non modificare

## Output
Stack, cos'è, architettura, dipendenze core, vocabolario, convenzioni, sprint, decisioni critiche, dove iniziare
