# /doc — Genera documentazione tecnica

## Input
Codice selezionato o specificato. `@.claude/memory/conventions.md`, `decisions.md`, `domain.md`. Template da `snippets/doc-patterns.md`.

## Regole
- No codice — spiega intenzione e contratto
- Sempre almeno un esempio funzionante
- Documenta errori, non solo happy path
- Non scrivere senza conferma
- Usa vocabolario dominio

## Output
API endpoint, Service, Componente UI, Funzione, o Modulo — template compilato, chiedi dove inserire
